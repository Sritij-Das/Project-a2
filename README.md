# Multiplication Table Generator 🧮

A simple, interactive Python program that generates multiplication tables based on user input. The program allows users to generate a table up to 10 or choose their own multiplication range.

## 📌 Project Overview

The **Multiplication Table Generator** is a beginner-level Python project developed to practise fundamental programming concepts such as loops, conditional statements, user input, and flow control.

It provides an interactive experience where users can generate multiple multiplication tables without restarting the program.

## ✨ Features

- **User Input:** Enter any number to generate its multiplication table.
- **Default Range:** Generate multiplication tables up to 10.
- **Custom Range:** Choose your preferred number of multipliers.
- **Interactive Execution:** Generate multiple tables in a single session.
- **Input Validation:** Handles unsupported Y/N commands.
- **Case-Insensitive Input:** Accepts both uppercase and lowercase Y/N responses.

## 🛠️ Technologies Used

- **Programming Language:** Python 3
- **IDE:** Any Python-supported code editor (VS Code, PyCharm, IDLE, etc.)

## 🧠 Python Concepts Implemented

| Concept | Purpose |
|---|---|
| `while` loop | Repeats the program until the user exits. |
| `for` loop | Generates the multiplication table. |
| `if-elif-else` | Handles user choices. |
| `break` | Terminates the loop. |
| `continue` | Restarts the current loop iteration. |
| `input()` | Accepts user input. |
| `int()` | Converts input into an integer. |
| `f-strings` | Displays formatted multiplication results. |
| `strip()` and `lower()` | Handles spaces and uppercase/lowercase responses. |

## 🚀 How to Run the Project

**Step 1:** Clone the repository.

```bash
git clone https://github.com/Sritij-Das/multiplication-table-generator.git
```

**Step 2:** Navigate to the project directory.

```bash
cd multiplication-table-generator
```

**Step 3:** Run the Python file.

```bash
python multiplication_table.py
```
